# Manga FX Maker

手描き風に揺れながら動く**集中線・流線・怒りマーク(💢)・汗・文字(!?等)・もやもや**の
透過アニメ素材を生成し、GIF / MP4 / WebM / 連番PNG で書き出せるツール。
画像読み込み不要のジェネレーターで、配信のツッコミ演出・動画編集の重ね素材向け。

## 使い方

1. `run_app.bat` をダブルクリック(サーバー不要・完全オフライン動作)
2. エフェクトの種類を選ぶ → 色・本数・大きさなどを調整
3. 「配置をシャッフル」で線のランダム配置を引き直し
4. 好きな形式で書き出し(背景「透過」ならそのまま重ねられる透過素材に)

## 揺れ(ボイル)の仕組み

- 配置は全コマ共通のシード、コマごとの微小なズレは別シードで生成
  → 「同じ絵を描き直した」ように線がわずかに揺れて見える(ラインボイル)
- 「揺れの強さ」0で完全静止、上げるほどラフな手描き感

## ファイル構成

- `index.html` — アプリ本体(6種のエフェクトはすべてCanvasプロシージャル描画)
- `exporter.js` — 共通書き出しモジュール(GIF/MP4/WebM/連番PNG。姉妹アプリと共通)
- `gifenc.js` — 自作GIF89a+LZWエンコーダー
- `lib/` — 同梱OSS: gifenc(適応パレット) / mp4-muxer(MP4) / JSZip(ZIP)。全てMIT、ライセンス全文同梱

## 姉妹アプリ

- `F:\dev\line_boil_app` — Line Boil Maker(線画の手描き風揺れ)
- `F:\dev\idle_motion_app` — Idle Motion Maker(立ち絵の待機モーション)
- `F:\dev\logo_shine_app` — Logo Shine Maker(ロゴ光沢スイープ)
