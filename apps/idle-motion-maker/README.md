# Idle Motion Maker

立ち絵・マスコットのPNGを読み込むだけで、浮遊・呼吸・ゆれ・跳ね・ぷるぷる等の
「待機モーション」ループアニメ素材を GIF / MP4 / WebM / 連番PNG で書き出せるツール。
配信の待機画面、ゲームのNPC、Live2Dを使うほどではない「とりあえず動いてほしい」用途に。

## 使い方

1. `run_app.bat` をダブルクリック(サーバー不要・完全オフライン動作)
2. 透過PNGの立ち絵をドラッグ&ドロップ / クリック選択 / Ctrl+V(白背景画像は自動透過)
3. プリセット(ふわふわ浮遊 / のんびり呼吸 / ぷるぷる / ぴょこぴょこ)を押すか、スライダーで自由に組み合わせ
4. 好きな形式で書き出し

## モーションの仕組み

- すべてサイン波ベースで**完全ループ**(周期の整数倍で必ず元に戻る)
- 足元(下端中央)基準の変形なので、呼吸・ゆれ・跳ねが自然に見える
- 跳ねには着地でつぶれ・跳躍で伸びるスクワッシュ&ストレッチ入り
- はみ出さないよう変形量から余白を自動計算

## ファイル構成

- `index.html` — アプリ本体
- `exporter.js` — 共通書き出しモジュール(GIF/MP4/WebM/連番PNG。姉妹アプリと共通)
- `gifenc.js` — 自作GIF89a+LZWエンコーダー
- `lib/` — 同梱OSS: gifenc(適応パレット) / mp4-muxer(MP4) / JSZip(ZIP)。全てMIT、ライセンス全文同梱

## 姉妹アプリ

- `F:\dev\line_boil_app` — Line Boil Maker(線画の手描き風揺れ)
- `F:\dev\manga_fx_app` — Manga FX Maker(動く集中線・漫符)
- `F:\dev\logo_shine_app` — Logo Shine Maker(ロゴ光沢スイープ)
