# Logo Shine Maker

ロゴ・タイトル画像を読み込むだけで、**キラッと光が走る／虹色に輝く**ループアニメを付与し、
GIF / MP4 / WebM / 連番PNG で書き出せるツール。サムネイル・配信オーバーレイ・OP演出向け。

## 使い方

1. `run_app.bat` をダブルクリック(サーバー不要・完全オフライン動作)
2. 透過PNGのロゴをドラッグ&ドロップ / クリック選択 / Ctrl+V(白背景画像は自動透過)
3. モードを選ぶ:
   - **光沢スイープ(白)** — 定番の白い光の帯が走る
   - **虹色スイープ** — 帯が虹色に変化しながら走る
   - **ホログラム(全体虹)** — ロゴ全体の色相が流れるように変わる
4. 角度・帯の幅・強さ・周期を調整し、好きな形式で書き出し

## 仕組み

- 光の帯はロゴのアルファチャンネルでマスクされるので、**ロゴの形の中だけ**を光が通る
- キラ粒子はロゴの不透明部分からランダムに配置され、位相をずらして明滅(完全ループ)
- スイープ位置・色相・粒子の明滅すべてが周期に同期しているため、つなぎ目のないループ素材になる

## ファイル構成

- `index.html` — アプリ本体
- `exporter.js` — 共通書き出しモジュール(GIF/MP4/WebM/連番PNG。姉妹アプリと共通)
- `gifenc.js` — 自作GIF89a+LZWエンコーダー
- `lib/` — 同梱OSS: gifenc(適応パレット) / mp4-muxer(MP4) / JSZip(ZIP)。全てMIT、ライセンス全文同梱
